Imported transactions are filed under an account. A bank alert that names a card's last four digits goes to the account with those digits (the Last 4 digits box on the Accounts page). Anything else goes to the account chosen here, or stays Unassigned for you to sort on the Transactions page.

Import from an older Budget Tool

Brings an old instance's transactions, categories, accounts, merchant rules and recurring items into this one. It never touches the old database — it takes a consistent snapshot first, so it is safe to run while the old instance is still going.

Running it twice imports nothing the second time, so if you are unsure whether a previous attempt finished, just run it again. Your current budgets are left alone: a category that already exists here keeps its own settings rather than taking the old one's.

Merchant rules (auto-categorization)

If a transaction's merchant contains the match text, it gets the category automatically — and any tags you add here. Rules are usually created for you from the “needs a category” inbox.

The amount boxes are optional and read as plain amounts, the way a statement shows them: leaving both blank means the rule matches any amount. They are what lets one merchant have two answers — “AMAZON up to $20” filed as Household and “AMAZON from $20.01” as Shopping. Where two rules both match, the higher priority wins, and failing that the longer match text.

Emails this app sends

{% if features.security_email %}

Security. When repeated wrong passwords lock the login, an email goes to the address below. You get one email for each run of wrong passwords, not one per attempt; the next waits until someone signs in with the right password. So a quiet inbox does not mean the guessing has stopped.

{% endif %} {% if features.money_alerts %}

Daily digest. One message a day at 07:00, and only on a day that has something in it — a bill due in the next few days, a subscription whose price went up, a category over its budget, or email ingestion having stopped. Each item is sent once: a category that is over budget is not reported again until the following month. This one goes to you alone and is never copied to a host.
